## 🚀 How to Open and View
Simply double-click `index.html` to open directly in any modern browser (Chrome, Edge, Firefox, Safari).

Or run a local static server:
```bash
npx serve .
```

## 📸 Profile Photo Customization
To update your profile photo, simply place your picture file as `assets/profile.jpg` in the `assets/` folder. The website will automatically display it in the curved hero frame with an elegant fallback avatar monogram if the image is loading.
